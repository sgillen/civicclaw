The housing story this week is [550 OFARRELL ST](https://sfplanninggis.org/pim?search=2025-000571PRJ) (140 units, State Density Bonus) is now on hold; [450 OFARRELL ST](https://sfplanninggis.org/pim?search=2013.1535) (261 units, State Density Bonus) is now closed; [400 DIVISADERO ST](https://sfplanninggis.org/pim?search=2024-005464PRJ) (203 units, AB 2011 + State Density Bonus) is now closed - approval ltr issued.

Against the citywide benchmark in the build-timelines reference, the notable thing here is not that individual market-rate projects take time after approval — that's normal — but how often the pipeline flips to on hold before permits ever show up. For a pro-building reader, the question stays structural: what is actually getting financed versus merely entitled.
