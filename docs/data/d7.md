## Citywide
Budget season is still the main citywide frame: the Board advanced the interim budget and salary ordinances, while committees kept moving charter amendments and code cleanup that will outlast this week's headlines. Housing remains stuck in the familiar gap between entitlement and construction, so the most important citywide question is still whether legislation and funding changes actually shorten that dead zone or just rearrange process on paper. Transit and street-management items matter when they change curb use, temporary street permits, or the balance between access and enforcement, but this week's highest-leverage public input is still at Board and committee hearings rather than in a separate citywide calendar dump.
