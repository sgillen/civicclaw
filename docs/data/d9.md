# District 9 Weekly Civic Digest

## TLDR
- District 9's sharpest signal this week is not a new project but a renter-stability shock: 24 eviction notices in 14 days, almost all clustered in the Mission and driven by non-payment filings.
- Land Use still matters for D9 because the same preservation-heavy landmark package touching Mission and nearby neighborhoods is moving with broader planning code amendments.
- Mission 311 volume remains high but not random: street and sidewalk cleaning, parking enforcement, graffiti and encampment reports are all concentrated on familiar corridors like 24th, Valencia, Capp and Shotwell.
- Fielder's week is tied to the same Board budget and charter-amendment cycle everyone is living through, but District 9 residents have a more immediate tenant-protection reason to pay attention.
- If you only track one citywide item beyond the eviction spike, track the Housing Trust Fund amendment rather than generic budget chatter.

## Citywide
Budget season is still the main citywide frame: the Board advanced the interim budget and salary ordinances, while committees kept moving charter amendments and code cleanup that will outlast this week's headlines. Housing remains stuck in the familiar gap between entitlement and construction, so the most important citywide question is still whether legislation and funding changes actually shorten that dead zone or just rearrange process on paper. Transit and street-management items matter when they change curb use, temporary street permits, or the balance between access and enforcement, but this week's highest-leverage public input is still at Board and committee hearings rather than in a separate citywide calendar dump.
